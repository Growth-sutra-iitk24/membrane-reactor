# Membrane Reactor Simulator

A web-based chemical reactor simulation application built using
Python, object-oriented programming, Streamlit, NumPy, SciPy,
Pandas, and Matplotlib.

## Features
- Editable reactor and kinetic parameters
- Initial molar flow rate inputs
- Numerical solution using SciPy solve_ivp
- Molar flow rate versus reactor volume plots
- Outlet flow rate display
- Downloadable CSV results

## Run locally

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run app.py
